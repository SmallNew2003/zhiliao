# @deepseek-ai/dsh-client-ui-memory-browser

[English](README.md) | 中文

## 概述

在 Web 侧栏选择**记忆**，查看部署的长期记忆里有什么。面板列出 daemon 持有的每个记忆库及其事实数与最后写入时间；对选中的库展示节点、链接、文档总数，事实类型与链接类型构成（按数量降序的条形图），其记忆单元，以及其知识页。知识页在库之上打开并显示渲染后的正文，搜索框检索该库的知识索引，便于直接跳到提及某个词的页面。记忆单元区也是你写入的地方：记录一条值得保留的发现，或策展一条后端已经持有的事实。

<a id="use-this-package"></a>
## 使用本包

只要 Host 装配了 `memoryController` Remote，面板就会出现在侧栏。它在首次渲染时读取 Host，因此不主动打开就不花任何代价；**刷新**与重连时会重新读取——在浏览器运行期间重启过的 daemon可能给出不同答案。

### 读取记忆库

列表展示 daemon 持有的每个库：名称、事实数，以及最后写入时间，显示为紧凑的相对时间（`3h`、`2d`）。相对时间的分桶与会话列表共用，因此两个界面不会对「5 分钟」何时结束产生分歧。从未写入过的库显示**尚无写入**，而不是留一个空时间。选择某个库即打开它；**刷新**会同时重读列表与当前打开的库。

记忆库按最后写入时间从新到旧排列，因此会话正在填充的那个库排在最前。后端从未写入过的库沉到末尾而不是消失；时间相同的库之间按名称决定顺序——每次刷新都重排的列表无法阅读。

### 读取单个库的构成

选中的库展示五个总计——节点、链接、文档、待处理操作、失败操作——以及后端上报的两组分布：按**事实类型**统计的节点数与按**链接类型**统计的链接数。每个分布以带标签的条形图绘制，按其最大项缩放，从大到小排列。后端未上报的分布用文字说明，而不是画一排零宽度的条——后者读起来像「已测量且为空」，而不是「未上报」。

待处理与失败的操作计数是后端上报的，不是本面板的判断。

### 读写记忆单元

在统计与知识页之间，面板列出该库的**记忆单元**——后端提取出的单条事实，统计只概括它们、从不展示。每行携带单元文本、作为标签的事实类型，以及被提及的时间，并带一个**编辑**入口，在行上打开该单元的字段。过滤框以对单元文本与上下文的大小写不敏感子串匹配收窄列表，页脚按后端对当前过滤的总数翻页；空过滤不构成一次运行，空结果会区分「这个库什么都没有」与「没有匹配的」。

**新增记忆**在列表上方打开一个表单：脱离上下文仍成立的发现，以及后端归档它时使用的可选上下文。提交即记录并刷新该库——保留通过运行推理来提取事实，因此提示会说提取完成后单元即可列出，后端有操作细节时显示在提示下方。单元上的**编辑**以预填值打开同样的字段，且草稿是权威的：保存会发送每个字段，因此清空上下文输入框即清空上下文。被后端拒绝的写入——hindsight 拒绝它派生的事实类型——以其原话保持表单打开；Host 无法应答的写入则显示与读取相同的分类提示。切换库会关闭进行中的草稿，因此一条写了一半的发现绝不会落入你离开的那个库。

### 浏览与搜索知识页

统计信息之下，面板列出该库的知识页，附带每页生成所用的提示词、最后刷新时间，以及后端标记为待刷新的页面的**待刷新**标签。打开某个页面会读取其正文并显示在库之上——统计与页面列表仍挂载在下方，因为知识页是对这个库的阅读，而不是离开这个库的步骤。页面角落的关闭控件，或返回记忆库列表的面包屑，都会关闭它。

搜索框检索该库的**知识索引**：整理好的知识页，按内容匹配。输入关键词后点**搜索**（或按 Enter）执行；结果行报告后端自己的总数，该数字可能大于显示的命中数。打开某个命中与打开页面列表中的页面方式相同。空输入框不算搜索——那会让 daemon 匹配全部内容，并按它自己的理解返回最好的二十页——因此没有关键词时**搜索**保持禁用。

这里刻意**不是**记忆 seam 的搜索。那个搜索由 daemon 运行推理作答，耗时一分钟以上，会让面板卡死；知识索引是索引查找。

### 记忆不可用时

没有装配记忆 provider 的部署没有可浏览的内容，面板会说明命中了哪种情况，而不是显示空列表或空白栏：

| 你看到什么 | 含义 |
|---|---|
| 本部署没有注册可用的记忆 provider | 该部署未启用记忆。 |
| 记忆 provider 配置有误 | Host 固定了一个未注册的 provider id，或有多个竞争而未固定。 |
| 记忆 daemon 没有在超时时间内应答 | daemon 在线但过慢，或不可达。 |
| 记忆 daemon 返回了错误 | 请求到达了 daemon 且被拒绝。 |
| 此记忆 provider 不支持该操作 | 该 provider 只服务 agent 路径、或不提供所要求的分区；库的其余部分继续渲染。 |

分类过的情形还会在句子下方显示 Host 自己的诊断信息，那里通常会指出需要修正的地址或 id。完全没有产生应答的调用——连接关闭、编解码不匹配——则改为显示传输层自己的话，只显示一次，并带**重试**按钮：这种失败值得重试，而没有 provider 的部署不值得。已经显示的记忆库会保留下来，因此一次网络抖动不会抹掉你正在读的内容。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现内部——点击展开</summary>

### 注册

浏览器插件通过 `ctx.slots.inject()` 注册 `memory` 侧栏条目及其 `main` 面板，因此两者都遵循后期槽声明、语言切换与拆卸。面板是全局的而非会话范围：部署记住了什么属于安装本身，而不属于某一段对话，且每个会话的侧栏都提供同一份视图。它注入 `remote.memoryController`，因此没有该 Remote 的 Host 会让面板根本不挂载，而不是半可用。

### Store

`MemoryBrowserController` 持有记忆库、选中的库、该库的统计、记忆单元与页面、打开页面的正文、搜索、写入草稿，以及任何失败。它不持有任何定时器，也不订阅任何东西：唯一跟随的失效信号是浏览器自身的重连，因为 daemon 可能在页面运行期间重启，而没有别的信号会通知它。读取会合并——慢加载期间的**刷新**只标记一次重跑，而不是为同一个答案向 daemon 问两次——而拆卸之后才到达的应答，或面板已切到另一个库之后才到达的应答，都会被丢弃，而不是写进一个已不属于它的视图。切换库还会清空离开的那个库的在途指示，因此一次仍在传输中的读取或写入不会让新库一直转下去。

记忆库列表、它的统计、它的单元、它的页面树是四个独立的 Remote 方法，因此其中一个失败不影响其他：daemon 无法测量的统计仍然列出它的单元，一次失败的读取也保留已经在屏幕上的内容，而不是清空一个可用的视图。provider 不提供的分区——不策展任何内容的后端上的统计或知识页——就地说明，而不是一言不发地消失。两项写入经同一条共享路径结算：传输拒绝与 Host 分类的拒绝成为写入自己的问题提示，后端拒绝以后端的 detail 保持表单打开，而受理的写入关闭表单、记下结果，并重新读取该库。

### 展示层

只有写入时间与五种不可用原因经过展示层辅助函数；两者都接受 `t` 而不是闭包捕获某本词典，因此语言切换能到达它们。相对时间分桶来自共享的 `relativeTime` 辅助函数，正是为了让本面板与会话列表保持一致；而具体措辞留在本包自己的词典里。本运行时无法解析的时间读作*从未写入*，而不是在列表中间显示一个未解析的后端字符串。

### 样式

只用 CSS Modules 与 `--dsw-*` 语义 token；没有字面颜色。分布条形图是唯一一处计算值进入 DOM 的地方，而它是宽度百分比，由计数推导而来，而不是颜色。

</details>

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>


这些限制说明这个浏览加写入视图能做什么。它们是当前包约束，不是任务积压。

- **搜索只覆盖知识页，不覆盖记忆**——查询跑在整理好的知识索引上，因为记忆 seam 的搜索由 daemon 运行推理作答、耗时超过一分钟；这里的事实级辅助是单元过滤，它只扫描不排序。
- **无删除、无历史**——写入只记录与策展；这里不删除单元、不触发合并，也无法说明自上次读取以来发生了什么变化，并且不报告是哪个 provider 注册了。
- **一次一个库**——统计、单元、页面与搜索都针对选中的库；没有跨库视图或对比。

<a id="dev-note"></a>
### 开发备注

<details>
<summary>维护者的工作上下文——点击展开</summary>

`memory` 面板 id 在主槽命名空间中全局唯一，且不与 `memory` seam 的 Cordis 键冲突；侧栏条目与面板共用它，因此该条目选中的正是它自己注册的页面。页面的 `now` 每次渲染读取一次而非每行读取一次，这样两次绘制内两个记忆库的尾部标签不会互相矛盾。

每个 Remote 调用在一次交互中最多发出一次，且面板已经切换后到达的应答会被丢弃——一个已不再选中的库的迟到应答绝不能覆盖当前那个库，因为屏幕上的数字会悄悄属于另一个库。

</details>

**运行时不变式：** 不发布伴生检查。本包只拥有一个基于 Host 记忆事实的只读侧栏面板。
