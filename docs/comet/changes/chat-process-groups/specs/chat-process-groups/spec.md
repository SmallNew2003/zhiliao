# 会话执行组

English | 中文

## 正文分段

会话必须保留 Assistant 的可见正文，并把相邻正文段之间的连续过程内容聚合为独立执行组。分组只改变展示，不改变持久化的 Session 顺序或模型可见内容。

### Scenario: Assistant 正文分隔执行组

- **WHEN** 一个轮次包含“过程内容、可见 Assistant 正文、过程内容、可见 Assistant 正文、最终回答”
- **THEN** 两段可见正文都留在执行组之外并保持原顺序
- **AND** 每段连续过程内容分别形成一个执行组
- **AND** 首个正文之前的独立过程内容也可以形成执行组

### Scenario: 单个 Assistant Node 按内容分拆

- **WHEN** 一个 Assistant Node 同时包含非空推理块和可见回复块
- **THEN** 推理块进入所在执行组
- **AND** 可见回复块留在执行组之外
- **AND** 同一内容块不会重复渲染

### Scenario: 独立行不进入执行组

- **WHEN** 轮次中出现用户消息、steering、系统提示词、错误、最大 token 提示或轮次尾部
- **THEN** 该行保持独立并按原顺序渲染
- **AND** 它成为相邻执行组之间的边界

## 运行与完成状态

执行组必须根据自身是否仍有后续正文或轮次结束来区分运行中与已完成状态。

### Scenario: 运行中的组默认展开

- **WHEN** 执行组仍处于运行中
- **THEN** 组默认展开
- **AND** 标题显示当前活动状态和该执行组已经过时间
- **AND** 进行中的思考或工具行显示运行状态

### Scenario: 已完成组显示摘要并默认收起

- **WHEN** 后续可见 Assistant 正文出现或轮次结束关闭执行组
- **THEN** 组默认收起
- **AND** 仅含思考的组显示“分析请求”
- **AND** 含工具调用的组根据组内实际动作生成简短摘要
- **AND** 存在失败调用时追加“部分操作失败”

### Scenario: 完成摘要只描述动作类型

- **WHEN** 一个已完成执行组包含一种或多种工具动作，且这些调用不是全部来自同一个 MCP server
- **THEN** 组标题最多描述两类主要动作，例如“读取文件、运行命令”
- **AND** 标题不显示任何调用次数
- **AND** 动作类型以执行组内去重后的工具调用归类
- **AND** 存在超过两类动作时在描述后追加“等操作”

### Scenario: 展开组限高并内部滚动

- **WHEN** 用户展开一个执行组
- **THEN** 组内过程区域最大高度为 `min(400px, 50vh)`
- **AND** 内容超出高度时在执行组内部滚动
- **AND** 可继续向上或向下滚动时对应边缘显示渐隐提示

### Scenario: 组内过程保持紧凑且可独立展开

- **WHEN** 执行组展开并包含多条思考或工具行
- **THEN** 每行保持现有紧凑摘要形态
- **AND** 连续同名工具调用可以收进二级分组
- **AND** 已完成、失败和进行中状态可区分
- **AND** 思考行和工具行仍可各自展开详情

## 交互与展示模式

### Scenario: 组标题支持键盘和指针操作

- **WHEN** 用户点击执行组标题或聚焦后按 Enter 或 Space
- **THEN** 执行组切换展开状态
- **AND** 标题暴露 `aria-expanded`
- **AND** 展开前的焦点停留在标题上

### Scenario: 页内查找揭示隐藏过程

- **WHEN** 浏览器页内查找命中已收起执行组内的文字
- **THEN** 对应执行组自动展开并显示命中内容

### Scenario: Compact 使用执行组

- **WHEN** 会话展示设置为 `Compact`
- **THEN** 符合条件的连续过程内容使用执行组
- **AND** 运行中组展开、已完成组收起

### Scenario: Normal 保持平铺

- **WHEN** 会话展示设置为 `Normal`
- **THEN** 过程行按现有平铺方式显示
- **AND** 不显示执行组标题、二级工具分组或组级限高
- **AND** 工具行仍使用与 `Compact` 相同的可读 MCP 名称和完成时文案

### Scenario: 流式追加与历史分页保持顺序

- **WHEN** 执行组内容流式增长、轮次完成或历史分页改变已加载窗口
- **THEN** 既有成员和二级分组保持稳定 key 和相对顺序
- **AND** 用户手动展开状态仅在对应组或二级分组仍存在时保留
- **AND** 不因重新渲染改变工具或思考节点已选择的状态

## 本地化与可访问性

### Scenario: 执行组文案来自本地化字典

- **WHEN** 执行组显示运行状态、完成摘要、失败状态或二级分组标题
- **THEN** 执行组文案来自 `ui-chat` 的本地化字典
- **AND** 工具行文案来自 `ui-tool` 使用的会话本地化字典
- **AND** 中文与英文均覆盖全部新增键

### Scenario: 运行状态不依赖颜色单独表达

- **WHEN** 执行组、二级分组或组内行处于运行中
- **THEN** 同时提供文本或状态语义
- **AND** 动画在 `prefers-reduced-motion` 下停止

## 工具名称与二级分组

工具行的名称和分组必须让用户直接看出调用了什么，而不是暴露 wire 名称。二级分组只减少重复，不改变执行组顶层的动作摘要规则。

### Scenario: 完成组标题标识 MCP 集成

- **WHEN** 一个已完成执行组的所有工具调用都来自同一个 MCP server
- **THEN** 组标题显示“已使用 {server} 集成”
- **AND** 运行中的同一组显示“正在使用 {server} 集成”与该执行组已经过时间
- **AND** 混合来源或非 MCP 的组沿用动作类型摘要
- **AND** 顶层标题仍不显示调用次数
- **AND** 存在失败调用时仍追加“部分操作失败”

### Scenario: 工具行隐藏 MCP 原始前缀

- **WHEN** `Compact` 或 `Normal` 模式渲染 `mcp__<server>__<tool>` 调用
- **THEN** 行摘要显示可读工具名和参数摘要，不显示 `mcp__<server>__` 前缀
- **AND** 无法解析的名称至少移除 `mcp__` 前缀后原样显示
- **AND** 工具行的展开体、错误摘要和状态语义保持不变

### Scenario: 组内连续同名工具调用形成二级分组

- **WHEN** 展开的执行组内出现至少 2 次连续、同 wire name、无 PTC 子调用的根工具调用
- **THEN** 这些调用被包在一个二级披露中
- **AND** 二级标题显示可读工具名与“{count} 次调用”
- **AND** 少于 2 次、不同工具、PTC 子调用、推理、重试或非工具行打断分组
- **AND** 顶层标题不显示该次数

### Scenario: 二级分组的展开与页内查找

- **WHEN** 用户点击二级标题，或聚焦后按 Enter 或 Space
- **THEN** 二级分组切换展开状态并保留成员挂载
- **AND** 手动展开状态仅在该二级分组仍存在时保留
- **AND** 页内查找命中折叠的二级内容时，外层执行组与二级分组都展开
- **AND** 二级分组内的工具行仍可独立展开

## 完成时行文案

工具行必须按调用状态使用进行时或完成时表述，让一排过程行读起来像动作记录而不是标签加参数。

### Scenario: 完成时行文案

- **WHEN** 工具行已结算（成功、失败或停止）
- **THEN** 标题使用完成时，例如读取→已读取、搜索→已搜索、命令→已运行、写入→已写入、编辑→已编辑、代码→已运行代码、网页→已访问网页、通用工具→已调用
- **AND** 运行中的行使用对应的进行时标题
- **AND** 句子行不显示圆点分隔符，标题与摘要之间使用单个空格
- **AND** 错误和停止行继续显示失败摘要与状态语义

### Scenario: 搜索行的作用域文案

- **WHEN** `grep` 调用带有 `path` 参数
- **THEN** 结算后的标题显示“已在 {path} 中搜索”，运行中显示“正在 {path} 中搜索”
- **AND** 摘要为引号包裹的 pattern
- **WHEN** 搜索调用没有 `path` 参数
- **THEN** 标题显示“已搜索”或“正在搜索”
- **AND** 摘要为引号包裹的 pattern

## 披露标题

### Scenario: 展开箭头位于标题右侧

- **WHEN** 执行组或二级分组渲染披露标题
- **THEN** 箭头位于标签右侧
- **AND** 不再使用左侧带边框的箭头容器
- **AND** 标题保留 `aria-expanded`、`aria-controls` 与点击后的焦点
- **AND** 运行中的箭头动画在 `prefers-reduced-motion` 下停止
