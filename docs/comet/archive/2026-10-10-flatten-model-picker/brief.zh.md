# 目标

[English](brief.md) | 中文

让用户点击输入框上的模型名称后，立即看到按提供方分组的模型列表，并在同一弹层调整当前模型的推理等级。先完成这一处 UI 改动，以当前工作区的实际页面和交互录像供用户评估。

# 范围

输入框模型选择弹层、局部样式、必要的中英文文案、所属包文档，以及受影响的组件测试、浏览器测试和界面快照。完整行为见 [模型选择规格](specs/composer-model-picker/spec.zh.md)。

# 非目标

本次不调整侧栏、上下文记录、整体品牌或模型设置页，不新增模型搜索、模型推荐、提供方接入或模型路由规则，不改变 `/model` 命令的交互。合并、推送和发布不属于此次效果展示。

# 验收示例

- 在允许选择模型的会话中，点击模型入口一次即显示按提供方分组的模型列表，并标记当前模型；无需先点击“模型”子菜单。
- 当前模型支持推理等级时，同一弹层显示其提供方声明的等级及当前选中项；无推理能力时不显示等级区域，不创建任意等级或覆盖提供方默认值。
- 选择另一模型或推理等级成功后，入口显示 Host 确认的结果，弹层收起并将焦点还给入口；选择当前值只关闭弹层，不重复写入；既有保存范围和后续请求生效规则保持不变。
- 键盘方向键可在可操作选项间移动，Enter、Space 或既有 Tab 操作可选择；Escape 或 Shift+Tab 一次关闭弹层并回到入口，点击外部也可关闭；选择进行中不能重复提交。
- 目录加载中、目录失败可重试、部分提供方失败、空列表和选择失败均有明确显示；选择失败不伪造成功，不丢失原选择，可重试。
- 中文和英文、浅色和深色、常规桌面和 390px 窄视口下，弹层不超出视口，长名称和多选项可阅读或滚动，推理等级区域与模型列表分区明确。
- 提供当前 worktree 的真实 Web 页面效果与日期戳命名的交互 GIF，展示打开列表、选择模型以及支持时选择推理等级；相关组件测试、浏览器回归和拥有者快照完成更新与验证，并经过独立只读验收。

# 约束与不变量

复用现有 ModelDirectory、Host 选择接口、持久化和语言字典，不修改模型调用协议或 Session 格式。模型列表按提供方返回顺序分组；选择只影响既有规则指定的后续请求。保留不可用和锁定状态的操作约束。代码与演示均在独立 worktree 中完成，保护主目录已有改动。

# 决策

- 用户要求使用 Comet 流程，先改一块 UI 查看效果；本轮将模型选择扁平化作为首块。
- 用户已明确选择独立 worktree；分支为 `codex/flatten-model-picker`，目标分支为 `master`。
- 弹层上方直接展示模型，下方展示当前模型的推理等级，使用现有主题令牌；选择成功后立即收起，不增加确认按钮。
- 需求、测试和验收说明使用中文。Comet 正式文件沿用 Runtime 固定文件名；效果截图与录像使用日期戳。

# 验证预期

先用组件测试验证选择、焦点和失败状态，再通过当前 worktree 构建的受支持 Web profile 验证模型列表、推理等级及界面快照。浏览器演示使用隔离数据，目录选择使用仓库规定的浏览器覆盖配置。已有 `default-model` 和 `declared-reasoning` 场景作为回归入口，具体命令在实现阶段按最终差异选取。每个验收项均需独立只读 Verifier 提供证据；未执行项目不得标记通过。真实模型调用如因环境条件无法执行，需明确记录限制。
