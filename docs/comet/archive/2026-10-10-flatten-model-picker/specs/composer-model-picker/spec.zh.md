# 输入框模型选择

[English](spec.md) | 中文

## 入口与弹层

允许模型选择的普通会话在输入框工具栏显示模型入口；入口显示 Host 提供的模型名称及适用的推理等级。入口打开一个弹层，直接显示模型列表，不经过中间导航页。不可用入口和锁定状态继续遵守所属会话的既有约束。

## 模型列表

模型按提供方分组并保留目录顺序。每个选项具有可访问名称和选中状态，当前模型以勾选标识显示。长列表可滚动，长名称不撑出视口。界面不新增模型搜索或模型推荐。

## 推理等级

当前模型提供推理元数据时，列表下方以分隔线和“推理等级”标签展示可选等级。选项只来自当前模型提供方声明，保留其默认语义；没有提供方默认等级时，保留既有 Default 选项。模型没有推理元数据时不渲染这一分区。等级区域与模型列表同时可见，不打开第二层菜单。

## 提交与反馈

选择另一模型或等级使用现有 Host 接口。选择成功后更新入口、关闭弹层并恢复入口焦点，选择当前值仅关闭弹层。提交过程中禁止重复选择。失败保留原选择并显示既有可恢复错误。持久化范围、默认模型设置和运行中请求的语义不变；`/model` 命令保留自身交互并继续共享同一目录。

## 加载与恢复

打开弹层时刷新模型目录，直接在弹层内显示加载状态。目录失败显示重试按钮；部分提供方失败展示原因且不遮蔽其他可用提供方；无模型时显示空状态。仅目录中缺少某条记录不改变该模型是否可路由的既有判断。

## 键盘与布局

方向键在可操作选项之间移动；Enter、Space 和既有 Tab 选择行为可完成操作。Escape、Shift+Tab 或点击外部关闭弹层；键盘关闭恢复入口焦点。模型和推理等级各有明确的可访问分组名称，勾选状态与 Host 当前选择一致。弹层继承浅色和深色主题，支持中文和英文；390px 窄视口通过尺寸约束、滚动和必要换行保持选项可操作。

## 验证与效果展示

验收项以 [需求说明](../../brief.zh.md) 为准。组件测试覆盖选择和异常状态，浏览器回归覆盖真实 Host 选择与相应界面快照。效果展示使用本变更实际构建的页面，并提供日期戳命名的 GIF。演示不使用另一目录的运行实例，也不以静态原型替代实现验证。
